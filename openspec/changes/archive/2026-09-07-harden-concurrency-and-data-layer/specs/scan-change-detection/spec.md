# scan-change-detection（增量：GUI 扫描触发合并）

## ADDED Requirements

### Requirement: GUI 扫描 single-flight

GUI 的扫描触发入口（手动重扫、孤儿/残留处置后的自动重扫、启动扫描）SHALL 共用一个执行闸门：同一时刻至多一轮扫描在执行；扫描进行中的新触发 SHALL 被立即丢弃（不排队、不等待），由进行中的那轮扫描结束时刷新界面。丢弃 MUST NOT 产生副作用：不执行全量扫描、不追加历史快照、不发射多余完成事件。

#### Scenario: 并发触发只跑一轮

- **WHEN** 一轮扫描进行中时再次触发扫描（如处置残留的自动重扫撞上手动重扫）
- **THEN** 新触发被立即丢弃，全程只执行一轮全量扫描，历史快照只追加一条

#### Scenario: 扫描结束后闸门复位

- **WHEN** 进行中的扫描完成（成功或失败）
- **THEN** 后续扫描触发可正常开启新一轮扫描
