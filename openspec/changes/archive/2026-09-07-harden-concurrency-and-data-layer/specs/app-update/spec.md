# app-update（增量：更新弹窗渲染转义）

## ADDED Requirements

### Requirement: 更新界面动态内容转义

更新相关界面把动态字符串（当前/最新版本号、资产名等来自版本检查结果的值）渲染进 DOM 时，SHALL 对动态值做 HTML 转义后再插值；本地化文案自身携带的结构标记（如加粗标签）MUST 保留不受影响。扫描结果、回收站列表等既有渲染路径的转义行为保持不变。

#### Scenario: 版本号注入被转义

- **WHEN** 版本检查结果的版本号字段包含 HTML 特殊字符并被更新弹窗渲染
- **THEN** 该值以纯文本形式展示，不被浏览器解析为标签或属性

#### Scenario: 文案加粗标记保留

- **WHEN** 本地化文案自身包含加粗标记（如「当前 <b>v1</b>」）
- **THEN** 渲染结果仍显示加粗样式，转义仅作用于动态插值部分
